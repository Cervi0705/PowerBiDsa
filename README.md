📊 Microsoft Power BI Para Data Science — Data Science Academy (DSA)

Este repositório contém os projetos, relatórios e conjuntos de dados (datasets) desenvolvidos durante o curso Microsoft Power BI Para Data Science, oferecido pela Data Science Academy (DSA).

📂 Estrutura do Repositório

O repositório está organizado para facilitar a navegação entre os relatórios interativos e as fontes de dados utilizadas:

/dashboards (ou arquivos .pbix): Relatórios e dashboards desenvolvidos no Power BI Desktop.

/datasets (ou arquivos .csv, .xlsx): Bases de dados brutas e tratadas utilizadas na construção dos modelos e visualizações.

🎯 Objetivos e Conteúdos do Curso

Durante o curso, foram abordados conceitos fundamentais e avançados de Business Intelligence (BI) e Análise de Dados:

Importação e Carga de Dados: Conexão com diversas fontes de dados.

Tratamento e Modelagem de Dados: Limpeza, transformação e aplicação de boas práticas no Power Query.

Linguagem DAX (Data Analysis Expressions): Criação de colunas calculadas, medidas implícitas/explícitas e funções de inteligência de tempo.

Visualização de Dados e Storytelling: Escolha e personalização de gráficos, aplicação de filtros/segmentadores e design focado na experiência do usuário.

Análise Preditiva e Estatística: Integração de conceitos de análise exploratória com dashboards interativos.

🛠️ Tecnologias e Ferramentas Utilizadas

Power BI Desktop

Power Query

Linguagem DAX

Excel / CSV

🚀 Como Utilizar Este Repositório

Clonar o repositório:

git clone https://github.com/seu-usuario/PowerBiDsa.git


Visualizar os Dashboards:

Certifique-se de ter o Power BI Desktop instalado em sua máquina.

Abra qualquer arquivo .pbix na pasta correspondente.

Explorar os Datasets:

Os dados utilizados estão disponíveis na pasta de dados para consulta ou para recriar os relatórios do zero.
