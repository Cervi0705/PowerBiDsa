## 🎯 Conteúdos Abordados no Curso

Durante o curso, foram desenvolvidos diversos conceitos práticos em cada capítulo:

* **Importação e Carga de Dados:** Conexão com diversas fontes e formatos de arquivos.
* **Tratamento e Modelagem de Dados:** Limpeza, transformação e ETL utilizando o **Power Query**.
* **Linguagem DAX (Data Analysis Expressions):** Criação de métricas, colunas calculadas e análises temporais.
* **Visualização de Dados e Storytelling:** Construção de relatórios interativos, escolha correta de visuais e design de dashboards.
* **Análise Exploratória e Preditiva:** Aplicação de estatística e modelos de análise com dashboards dinâmicos.

## 🚀 Como Utilizar Este Repositório

1. **Clonar o repositório:**
   ```bash
   git clone https://github.com/Cervi0705/PowerBiDsa.git
   ```

2. **Acessar os Capítulos:**
   * Navegue até a pasta do capítulo desejado (`Cap02`, `Cap03`, etc.).
   * Abra os arquivos `.pbix` no **Power BI Desktop**.
   * Os dados utilizados nas práticas de cada capítulo também estão presentes na mesma pasta.
